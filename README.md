# Accurate Geometric Shape Visualizer (web)

Accurate Geometric Shape Visualizer (AGSV) is a webpage that aims to accurately visualize different shapes with given values. This project is designed for helping students to answer complex geometric questions that did not include graphs. Furthermore, AGSV can also supporting teachers to display shapes while teaching, which may save time and help students understand more.

## features

-   **create shapes:** with enough information inputed into the webpage, AGSV can create the desired shape for you.

-   **calculate information:** AGSV can calculate all the relevent information about a selected shape, including all the side length, angle size, and area.

*   **sharing between shapes:** AGSV allow users to create a shape based on a existing side or angle. when create a new shape, you can replace a piece of information with the name of a existing side or angle, this allows sharing side or angle between shapes.

*   **change the style:** by selecting on shape, or a component of the shape (a side, a dot or an angle), you can add some style to it so it can be more clear. AGSV support user to display angle size and side length to be displayed, give label to shapes and change the color of some of them.

*   user can use variables to represent informations including length or angle size
*   user can draw auxiliary lines
